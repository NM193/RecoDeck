**Step 3: Fix remaining manual clippy warnings.**

After auto-fix, run clippy again and address each remaining warning manually. Common categories:

a) **Unused variables**: Prefix with `_` (e.g., `_id` instead of `id`) or remove if truly unused.

b) **Unused imports**: Remove the import line.

c) **Redundant field names in struct initialization**: `role: role` becomes just `role`.

d) **Use `if let` instead of single-arm match**: Convert `match x { Some(v) => ..., None => {} }` to `if let Some(v) = x { ... }`.

e) **Unused `Result`**: If a function call returns `Result` and the result is ignored, either add `let _ =` or handle the error.

f) **Dead code warnings from Plan 01-01 migration**: Any new warnings introduced by the AppError migration (e.g., unused `use` statements from old String error pattern) -- remove them.
