**Step 1: Install the variable font package.**

Run:
```bash
npm install @fontsource-variable/inter
```

Use the variable font package (not `@fontsource/inter`) because:
- Variable fonts cover all weights in a single WOFF2 file (~100KB vs ~300KB for 3 separate weight files)
- RecoDeck uses 3 weights (400, 500, 700) so the variable font is more efficient
- Import is simpler: one CSS import instead of three

**Step 2: Add the font CSS import to src/main.tsx.**

Add this import BEFORE the globals.css import (so the font is available when globals.css body rule applies):
```typescript
import '@fontsource-variable/inter';
```

This line should be placed after the React/ReactDOM imports but before `import './styles/globals.css'`.

**Important notes:**
- Do NOT add Google Fonts CDN links -- this is a desktop Tauri app that may run offline.
- Do NOT modify index.html -- font loading goes through the Vite build system via npm import.
- The variable font package automatically provides WOFF2 with latin subset, which is sufficient for a music library app.
