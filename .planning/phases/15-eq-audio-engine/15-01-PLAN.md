Add the following 5 public methods to the AudioPlayer class, near the existing `setCrossfadeEnabled`/`setCrossfadeDuration` methods (around line 68). All gain changes MUST use the `cancelScheduledValues + setValueAtTime anchor + linearRampToValueAtTime` pattern with 30ms ramp. No instant `setValueAtTime` for gain — always ramped per locked decisions.

**Method 1 — `setEqBandGain(index: number, dB: number): void`**
- Clamp dB to [-12, 12]
- Store in `_eqGains[index]`
- If `!this._eqEnabled`, return early (don't apply while bypassed — gains stored for re-enable)
- If `_eqFilters[index]` exists and `_vizCtx` exists:
  - `param.cancelScheduledValues(now)`
  - `param.setValueAtTime(param.value, now)` — anchor current value
  - `param.linearRampToValueAtTime(clampedDb, now + 0.03)` — 30ms ramp

**Method 2 — `setEqEnabled(enabled: boolean): void`**
- Set `this._eqEnabled = enabled`
- If no `_vizCtx` or empty `_eqFilters`, return (gains will apply when getAnalyser() creates chain)
- For each filter: ramp gain to `enabled ? _eqGains[i] : 0` using the same cancel+anchor+ramp pattern

**Method 3 — `setAllBands(gains: number[]): void`**
- For each of the 10 bands: clamp to [-12, 12], store in `_eqGains[i]`
- If EQ enabled and filters exist: ramp each filter gain to the new value using cancel+anchor+ramp
- If EQ disabled: just store (no filter application)

**Method 4 — `loadEqState(state: { enabled: boolean; bands: number[] }): void`**
- Set `_eqEnabled = state.enabled`
- Set `_eqGains = state.bands.slice(0, EQ_BANDS.length)` — pad with 0 if shorter
- If filters already exist and _vizCtx exists: ramp each filter to target using cancel+anchor+ramp
- If filters don't exist yet: gains stored in _eqGains, applied during getAnalyser() init (Task 1 already handles this)

**Method 5 — `getEqState(): { enabled: boolean; bands: number[] }`**
- Return `{ enabled: this._eqEnabled, bands: [...this._eqGains] }` — return a COPY, not the internal array

**DRY helper (private):** Extract the cancel+anchor+ramp pattern into a private helper to avoid repeating it in every method:
```typescript
private _rampEqGain(filter: BiquadFilterNode, targetDb: number): void {
  if (!this._vizCtx) return
  const now = this._vizCtx.currentTime
  filter.gain.cancelScheduledValues(now)
  filter.gain.setValueAtTime(filter.gain.value, now)
  filter.gain.linearRampToValueAtTime(targetDb, now + 0.03)
}
```

Then use `this._rampEqGain(this._eqFilters[i], targetDb)` in all methods.

**Native PCM mode:** All methods are safe — they check `_eqFilters.length > 0` before touching filters. In native mode, `getAnalyser()` returns null (line 979), filter chain is never created, and EQ methods become no-ops that only store state in `_eqGains`. This is the documented acceptable behavior.
