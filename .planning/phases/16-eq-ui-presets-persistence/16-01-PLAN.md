**EQModal.tsx:**

Props interface:
```typescript
interface EQModalProps {
  open: boolean
  onClose: () => void
  onEnabledChange: (enabled: boolean) => void
}
```

Component behavior:
1. When `open` becomes true, read `audioPlayer.getEqState()` to initialize local state: `enabled`, `bands` (number[10]), `activePreset` (detected via `detectPreset(bands)`)
2. If `!open`, return null (don't render)

Layout (top to bottom):
- **Header row:** Title "Equalizer" on left, close button (X icon) on right
- **Controls row:** On/off toggle (checkbox styled as toggle switch), preset `<select>` dropdown with all 6 presets + "Custom" option
- **Sliders row:** 10 vertical `<input type="range">` sliders in a horizontal flex/grid row. Each slider: min=-12, max=12, step=0.1. Below each slider: frequency label from EQ_BANDS[i].label. Above each slider: current dB value formatted as "+6" or "-3" or "0"
- **Backdrop:** Fixed position overlay, closes on click

Slider behavior:
- On change: call `audioPlayer.setEqBandGain(index, value)`, update local `bands` state, run `detectPreset()` to update activePreset (if bands no longer match current preset, switch to 'custom')
- Use `writing-mode: vertical-lr; direction: rtl` via CSS class (same as volume slider pattern)
- Slider track background: use inline style with linear-gradient showing accent color for the gain portion (center is 0 dB)

Preset dropdown behavior:
- On change: if preset !== 'custom', get gains from `EQ_PRESETS[preset]`, call `audioPlayer.setAllBands(gains)`, update local bands and activePreset state
- 'custom' option is display-only (selected automatically when bands don't match any preset) — selecting it does nothing

Toggle behavior:
- On change: call `audioPlayer.setEqEnabled(value)`, update local `enabled` state, call `onEnabledChange(value)` prop

Debounced persistence (useRef timeout pattern):
- After ANY state change (band, preset, toggle), debounce 300ms then call `tauriApi.setSetting('eq_state', JSON.stringify({ enabled, bands, preset: activePreset }))`
- Clear timeout on unmount
- Import tauriApi from `../../lib/tauri-api`

Close on Escape key: add keydown listener in useEffect when open.

**EQModal.css:**

Modal backdrop: `position: fixed; inset: 0; z-index: 1000; background: rgba(0,0,0,0.5); display: flex; align-items: center; justify-content: center`

Modal container: `background: var(--surface); border: 1px solid var(--border); border-radius: 12px; padding: 20px 24px; min-width: 520px; max-width: 600px; box-shadow: 0 8px 32px rgba(0,0,0,0.4)`

Slider styling: Copy the vertical range pattern from NowPlayingBar.css (writing-mode, -webkit-slider-thumb, -moz-range-thumb). Height: 120px. Track color: var(--border). Thumb color: var(--accent).

Slider column layout: Use CSS grid with 10 equal columns. Each column: dB label on top, slider in middle, frequency label on bottom. Center-aligned.

Toggle switch: Style checkbox as a toggle switch (pill shape with sliding circle). Use var(--accent) for active state.

Preset select: `background: var(--surface-hover); color: var(--text); border: 1px solid var(--border); border-radius: 6px; padding: 6px 12px; font-size: 13px`

All colors use CSS custom properties (var(--surface), var(--border), var(--text), var(--text-secondary), var(--accent), var(--surface-hover)) so both themes work automatically.

Use `eq-modal__` BEM prefix for all class names.
