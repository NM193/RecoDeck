## Spacing Scale

Declared values (4px base grid — matches project's existing `--space-*` tokens):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`--space-1`) | Icon gaps, inline padding, context menu item icon gap |
| sm | 8px (`--space-2`) | Compact element spacing, sidebar nav gap, conversation item internal gap |
| md | 16px (`--space-4`) | Default element spacing, chat input horizontal padding |
| lg | 24px (`--space-6`) | Section padding, conversation list header padding |
| xl | 32px (`--space-8`) | Layout gaps between major panels |
| 2xl | 48px (`--space-12`) | Empty state vertical padding |
| 3xl | 64px | Page-level spacing (not used in this phase) |

Exceptions:
- Conversation list panel width: 240px fixed (not a spacing token — structural layout value)
- Chat area takes remaining flex space (no fixed width)
- Touch targets (New Chat button, nav item): minimum 36px height — matches `--input-height`
- Sidebar nav item padding: 8px 10px — matches existing `.sidebar-nav-item` pattern

## Typography

All roles use Inter Variable. Four sizes from the project's existing scale:

| Role | Size | Weight | Line Height | CSS Token | Usage |
|------|------|--------|-------------|-----------|-------|
| Body | 13px | 400 (regular) | 1.5 | `--text-base` | Chat message content, conversation item title |
| Label | 11px | 400 (regular) | 1.4 | `--text-xs` | Relative date timestamp in conversation items, hint text below input |
| Heading | 14px | 600 (semibold) | 1.3 | `--text-md` | Chat view header: active conversation title; "New Chat" button text; section labels |
| Display | 24px | 600 (semibold) | 1.2 | `--text-2xl` | Empty state heading ("No conversations yet") |

Notes:
- Conversation title in header is editable on click — switches from Heading to an inline `<input>` using the same size/weight
- Typing hint below message input uses Label (11px, --text-xs, `--text-muted` color)
- Relative date stamps use Label color `--text-muted` (#6a6a6a in Midnight)

## Color

All values reference project CSS custom properties — work across all themes (Midnight, Carbon, Dawn, Custom, Neon).

| Role | CSS Variable | Midnight Hex | Usage |
|------|-------------|--------------|-------|
| Dominant (60%) | `--bg-primary` | #121212 | Chat area background, full-view base |
| Secondary (30%) | `--bg-secondary` / `--bg-tertiary` | #181818 / #282828 | Conversation list panel background (`--bg-secondary`); selected conversation item + nav items (`--bg-tertiary`) |
| Accent (10%) | `--accent` | #6366f1 (Midnight) | Active conversation item left-border indicator; "New Chat" button background; send button when active; scrollbar thumb hover |
| Destructive | `--color-danger` | #e53e3e (Midnight) | Delete conversation context menu item text |

Accent reserved for:
1. Active conversation item: 2px left border in `--accent`
2. "New Chat" button: solid `--accent` background (prominent, only one per view)
3. Send button: `--accent` background when input has text and is not generating
4. Selected conversation item: `--bg-tertiary` background (no accent fill — same as other active nav items)

Secondary color detail:
- Conversation list panel uses `--bg-secondary` to distinguish it from the chat area (`--bg-primary`)
- Chat header bar uses `--bg-secondary` with `1px solid var(--border)` bottom border — clean, no gradient
- User message bubbles: `--accent` background with white text (matches existing `ChatMessage.tsx` direction but uses `--accent` token instead of hardcoded blue)
- AI message bubbles: `--bg-tertiary` background, `1px solid var(--border)` border

## Interaction Contracts

### Conversation item states

| State | Visual |
|-------|--------|
| Default | `--text-secondary` title; `--text-muted` date; transparent background |
| Hover | `--bg-tertiary` background; `--text-primary` title |
| Active (selected) | `--bg-tertiary` background; `--text-primary` title; 2px `--accent` left border |
| Rename (inline edit) | Title replaced by `<input>`, same font/size; 1px `--border` bottom; no border-box |

### Context menu (right-click on conversation item)

- Trigger: `onContextMenu` on conversation item row
- Position: fixed at cursor x/y (same pattern as `.sidebar-ctx-menu`)
- Dismiss: click outside (mousedown listener on `document`)
- Items:
  1. Rename — pencil icon; `--text-primary`
  2. Delete — trash icon; `--color-danger`
- Menu class: matches `.sidebar-ctx-menu` + `.sidebar-ctx-menu__item` CSS classes (reuse)

### Inline rename

- Enter key: save — call `renameConversation()` from tauriApi, update local state
- Escape key: cancel — restore original title, exit edit mode
- Blur: save (same as Enter)

### Delete flow

1. User right-clicks → selects Delete
2. Native Tauri `confirm("Delete this conversation and all its messages?")` dialog
3. OK: call `deleteConversation(id)`, remove from local list
4. If deleted conversation was active: clear `chatHistory`, set `currentConversationId` to null, show empty state in ChatArea
5. Cancel: dismiss, no changes

### New Chat

1. User clicks "New Chat" button
2. Call `createConversation()` — get new `conversation_id`
3. Set `currentConversationId` to new id, clear `chatHistory`
4. New conversation appears at top of list (unshift)
5. Auto-title updates in list after first message is sent (from Phase 28 auto-title logic)

### Load conversation

1. Click any conversation item
2. Call `getConversationMessages(id)` from tauriApi
3. Set `chatHistory` in aiStore to returned messages
4. Set `currentConversationId`, update localStorage `lastActiveConversationId`
5. Framer Motion `AnimatePresence` crossfade: old messages fade out, new messages fade in (200ms opacity transition)

### On-mount restore

1. ChatView mounts (user navigates to "AI Chat" in sidebar)
2. Call `listConversations()` — populate conversation list
3. Read `lastActiveConversationId` from localStorage
4. If value exists and matches an id in list: load that conversation
5. If value missing or not in list: show empty state in ChatArea

### Typing indicator

Three dots animation while `isGenerating === true`:
- Three 8px circles in `--accent` color
- `animate-bounce` with 0ms / 150ms / 300ms delays (matches existing AIChatPanel pattern)
- Text: "AI is thinking..." at 13px `--text-secondary`

### Send button states

| State | Visual |
|-------|--------|
| Empty input | Background `--bg-tertiary`; icon `--text-muted`; cursor not-allowed |
| Has input, not generating | Background `--accent`; icon white; cursor pointer |
| Generating | Background `--bg-tertiary`; icon `--text-muted`; disabled |

## Animation

| Interaction | Animation |
|-------------|-----------|
| Navigate to AI Chat view | Framer Motion crossfade: `opacity 0→1`, 150ms — matches existing view transitions in App.tsx |
| Switch conversation | ChatArea message list: `opacity 1→0→1`, 200ms, `AnimatePresence` key on `currentConversationId` |
| New message appears | `fade-in slide-in-from-bottom-2 duration-300` (matches existing `ChatMessage.tsx` animate-in class) |
| Context menu open | `opacity 0→1`, `scale 0.95→1.0`, 120ms |
| Conversation item delete | `AnimatePresence` exit: `opacity 1→0`, `height 0`, 200ms |
