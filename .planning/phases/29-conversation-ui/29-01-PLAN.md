**Initial state values:**

```typescript
conversations: [],
```

**Action implementations:**

`loadConversations`:
- Call `tauriApi.listConversations()`
- `set({ conversations: result })`
- Wrap in try/catch, log error on failure

`createNewConversation`:
- Call `tauriApi.createConversation()` which returns a `Conversation` object
- Unshift the new conversation to the front of `conversations` array
- Set `currentConversationId` to the new conversation's id
- Clear `chatHistory` to `[]`, clear `error` to null
- Save `conversation.id` to `localStorage.setItem('lastActiveConversationId', conversation.id)`

`loadConversation` (takes conversationId: string):
- Call `tauriApi.getConversationMessages(conversationId)` which returns `ConversationMessage[]`
- Map the result to `ChatMessage[]` format: `messages.map(m => ({ role: m.role, content: m.content, timestamp: new Date(m.created_at * 1000).toISOString() }))`
- `set({ chatHistory: mapped, currentConversationId: conversationId, error: null })`
- Save to localStorage: `localStorage.setItem('lastActiveConversationId', conversationId)`

`deleteConversation` (takes conversationId: string):
- Call `tauriApi.deleteConversation(conversationId)`
- Remove from local conversations array: `set(state => ({ conversations: state.conversations.filter(c => c.id !== conversationId) }))`
- If `conversationId === get().currentConversationId`, also set `currentConversationId: null, chatHistory: []` and `localStorage.removeItem('lastActiveConversationId')`

`renameConversation` (takes conversationId: string, title: string):
- Call `tauriApi.renameConversation(conversationId, title)`
- Update local conversations array: `set(state => ({ conversations: state.conversations.map(c => c.id === conversationId ? { ...c, title } : c) }))`

`setCurrentConversationId`:
- `set({ currentConversationId: id })`

**Modify existing `sendMessage` action:**
- After the existing line `const response = await tauriApi.aiChat(message, chatHistory)`, change it to pass `currentConversationId`:
  `const response = await tauriApi.aiChat(message, chatHistory, get().currentConversationId ?? undefined)`
- After a successful AI response is added to chatHistory, refresh the conversations list to pick up auto-title changes: call `get().loadConversations()` (the backend auto-titles the conversation from the first message)

**Modify existing `clearHistory` action:**
- Change from `() => set({ chatHistory: [], error: null })` to also clear conversation: `() => set({ chatHistory: [], error: null, currentConversationId: null })` and `localStorage.removeItem('lastActiveConversationId')`

Do NOT change any other existing functionality. All existing AI store actions (generatePlaylist, checkApiKeyStatus, setApiKey, etc.) must remain exactly as they are.
