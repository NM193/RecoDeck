   ```typescript

     if (import.meta.env.DEV) return
     const timer = setTimeout(async () => {
       try {
         const update = await check()
         if (update) {
           setPendingUpdate(update)
         }

         console.warn('Auto update check failed:', err)
       }
     }, 4000)
     return () => clearTimeout(timer)
   }, [])
   ```
   CRITICAL: No `downloadAndInstall()` call. No `relaunch()` call. check() only.
   Keep the `import.meta.env.DEV` guard (existing convention).

5. Render UpdateToast in the JSX (near the existing Notification render):
   ```tsx
   {pendingUpdate && (
     <UpdateToast
       version={pendingUpdate.version}
       onInstall={() => {
         setPendingUpdate(null)
         setShowSettings(true)
         setSelectedFolder(null)
         setSelectedPlaylistId(null)
         setShowAllTracks(false)
         setShowSearch(false)
       }}
       onLater={() => setPendingUpdate(null)}
   ```
