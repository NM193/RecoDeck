Remove all pagination from the "All Tracks" view — replace batched `getTracksPaginated` with a single `getAllTracks()` call, delete all pagination state and scroll-triggered loading, and simplify the footer to show only count and sort info.

Purpose: The pagination code (1000-track batches with scroll detection) adds complexity for no user benefit — SQLite loads the full library in milliseconds and TanStack Virtual already handles rendering. This cleanup removes dead weight.

Output: All 6 files cleaned of pagination code. The app loads every track on startup in one shot.
</objective>
