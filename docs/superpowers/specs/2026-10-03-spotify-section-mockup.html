With SPOTIFY collapsed, the new-likes count still shows in the sidebar — you know something is waiting without opening anything.

What each part does

Indigo dot next to a title: new since you last opened this list. It clears once you have seen the list.
Copy copies Moreno & Prieto, Sortech - 300 Cash and flips to "Copied" for a second.
Spotify icon plays the track on Spotify — right away with Premium and Spotify open somewhere, otherwise it opens the track in the Spotify app.
↗ opens the track's search on SelectedRecs.
Maybe: the name match is not certain. The row below says which file it thinks it is; "Yes" / "No" is remembered.
All playlists adds a "Playlist" column, so you can see where each track came from.
Double-clicking a track you own plays it from the library, like everywhere else in the app.
